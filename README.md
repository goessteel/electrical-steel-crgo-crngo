### CRGO vs. CRNGO at a glance

| | CRGO (Grain-Oriented) | CRNGO (Non-Oriented) |
|---|---|---|
| Magnetic properties | Strongly directional (rolling direction) | Nearly the same in all directions |
| Typical silicon content | ~3% | 0.5% – 3.0% |
| Main use | Transformer cores | Rotating machines: motors, generators, EV traction motors |
| Core loss | Very low in rolling direction | Low, isotropic |
